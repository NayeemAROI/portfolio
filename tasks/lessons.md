# Lessons

- Always enter plan mode for non-trivial builds and track progress in `tasks/todo.md`.
- Keep implementation mobile-first, then layer desktop enhancements.
- Prefer minimal, high-impact structure and avoid over-engineering in first pass.
- Validate by inspecting generated files and project status before finalizing.
- After user correction on stack expectations, align implementation stack explicitly (e.g., React app scaffolding instead of static HTML only).
